# أداة فحص الكمبيوتر الشاملة (Professional Laptop Inspector) 💻

هذه الأداة هي تطبيق سطح مكتب احترافي مصمم خصيصاً لفحص أجهزة الكمبيوتر المحمولة (Laptops) التي تعمل بنظام **Windows 10/11**. تم بناء التطبيق باستخدام لغة **Python** وواجهة رسومية عصرية بواسطة **CustomTkinter**.

## ✨ الميزات الأساسية
*   **المواصفات العتادية:** عرض تفصيلي للمعالج (CPU)، كرت الشاشة (GPU - NVIDIA)، والذاكرة العشوائية (RAM).
*   **صحة التخزين (S.M.A.R.T):** فحص أقراص الـ NVMe/SSD ومعرفة حالتها الصحية وموديلاتها.
*   **صحة البطارية:** قراءة السعة التصميمية، السعة الحالية، ومستوى التآكل (Wear Level) بالإضافة لعدد دورات الشحن.
*   **مراقبة الحرارة:** عرض درجات حرارة المعالج وكرت الشاشة في الوقت الفعلي.
*   **اختبار الضغط (Stress Test):** اختبار استقرار الجهاز تحت ضغط كامل لمدة 30 ثانية.
*   **فحص البكسلات الميتة:** شاشة كاملة تتنقل بين الألوان لاكتشاف أي عيوب في الشاشة.
*   **تصدير التقارير:** حفظ كافة نتائج الفحص في ملف نصي (TXT) باللغة العربية على سطح المكتب بضغطة زر.

## 🛠️ المتطلبات المسبقة
يجب تثبيت لغة Python (إصدار 3.8 أو أحدث) ثم تثبيت المكتبات اللازمة عبر الأمر التالي:

```bash
pip install customtkinter psutil wmi GPUtil py-cpuinfo pillow setuptools
```

## 🚀 كيفية الاستخدام
1.  قم بتحميل ملف `laptop_inspector.py`.
2.  افتح موجه الأوامر (CMD) أو PowerShell كمسؤول (**Run as Administrator**) لضمان قدرة الأداة على الوصول لبيانات العتاد الحساسة (مثل حرارة المعالج وصحة القرص).
3.  قم بتشغيل الأداة عبر الأمر:
    ```bash
    python laptop_inspector.py
    ```

## 📝 ملاحظات تقنية
*   تعتمد دقة قراءة درجات حرارة المعالج وصحة البطارية على دعم اللوحة الأم وبرامج القيادة (Drivers).
*   يُفضل تشغيل الأداة وصلاحيات المسؤول (Admin) مفعلة للحصول على كافة البيانات.
